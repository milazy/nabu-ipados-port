# nabu iPadOS 17.7 (21H16): feature status, 2026-11-12

Historical batch 3–5 snapshot. For the CRC-verified batch-6 investigation,
batch-7 candidate hashes, current qualification table and recovery procedure,
see [Batch 7 hardware evidence](BATCH7_HARDWARE_EVIDENCE.md).

Three levels, kept separate:
- **compiled**: the code builds in CI.
- **attached**: it is installed on the tablet and its boot-log marker shows it loaded or mounted.
- **end-to-end**: the user-visible function was observed working on the tablet.
