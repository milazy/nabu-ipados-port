The public completion-wait patch was rejected before installation. It removes handler dispatch-group waits, but Apple's waitUntilCompleted contract explicitly includes completion handlers: https://developer.apple.com/documentation/metal/mtlcommandbuffer/waituntilcompleted() . The archived guide also includes scheduled handlers in waitUntilScheduled: https://developer.apple.com/library/archive/documentation/Miscellaneous/Conceptual/MetalProgrammingGuide/Cmd-Submiss/Cmd-Submiss.html . A harness expecting those calls to return while handlers remain pending would test the wrong contract. Initial combined build 42811710285 was cancelled and its candidate is not eligible for deployment. The corrected candidate keeps both wait methods unchanged.
