# nabu Wi-Fi (WCN3998, ath10k SNOC) - plan, 12 Nov 2026

Owner priority from batch 3 on: Wi-Fi only.

## Hardware (Linux mainline sm8150.dtsi, to be confirmed against the unit's own FDT)
- WLAN: `wifi@18800000` `qcom,wcn3990-wifi` (ath10k_snoc), 12 CE IRQs GIC SPI 414..425, `wlan_mem` 0x8bc00000 + 0x180000,
  SMMU SID 0x640, clock RPMH_RF_CLK2, supplies vdd-0.8-cx-mx, 1.8-xo, 1.3-rfa, 3.3-ch0/ch1.
- The WLAN firmware runs on the modem Q6: `remoteproc@4080000` `qcom,sm8150-mpss-pas` (PAS id 4, modem.mdt split image),
  `mpss_mem` 0x8d800000 + 0x9600000, power domains CX + MSS, AOSS QMP load_state "modem".
- smp2p-mpss: SMEM items 435/428, GIC SPI 451, APSS IPC mailbox bit 14; inbound bits fatal 0, ready 1, handover 2,
  stop-ack 3, shutdown-ack 7. GLINK edge "modem": GIC SPI 449, mailbox bit 12.
- `rmtfs_mem` 0x89b00000 + 0x200000 (client 1, VMID MSS_MSA): the modem needs an rmtfs server (modemst1/modemst2/fsg/fsc)
  and a TFTP server over QRTR for wlanmdsp.mbn (Linux: rmtfs, tqftpserv).
- XNU owns DRAM from 0xc0000000 on nabu, so every carveout above lies outside XNU memory.

  ath10k (core, snoc, ce, htc, htt, wmi-tlv, qmi) would be compiled on the same shim instead of ath12k.
- No UniXNU device has WCN399x Wi-Fi yet (enchilada/pclm10 records: not started).

## Stages (each a boot-argument-gated diagnostic first; no partition is ever written)
1. Inventory (read-only, TWRP): FDT, modem_b file list, wlanmdsp/bdwlan, partition LBAs. `tablet_wifi_inventory.sh`.
2. MPSS boot: read modem.mdt pieces from modem_b (read-only LBA window), PAS init/mem-setup/auth-and-reset, QMP + CX/MSS
   votes, wait for smp2p ready. Log only.
3. SMEM GLINK + QRTR to the modem, rmtfs and TFTP servers, QMI WLFW service visible.
4. ath10k_snoc on the Ath12kWifi shim: CE rings, HTC/WMI-TLV, MAC address, scan.
5. Apple side: WifiNet en0/Apple80211 + supplicant (iPadOS 17 ABI differs from sheng's iPadOS 27: to verify).

Faster interim path for internet (not selected by the owner yet): USB CDC-NCM gadget over DWC3 (nabu already prototyped
NabuUsbCaptureCdc.cpp; sheng has ShengEthernet.cpp), PC shares its connection.
